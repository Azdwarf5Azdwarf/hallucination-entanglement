# extended mind

Clark and Chalmers (1998): if a process outside the skull does the same functional job as a process inside it — reliably available, trusted, automatically used — it is not a helper. It is part of the thinking.

Parity principle. Location is an implementation detail.

Otto's notebook is the old demo. Phone calendar, maps, notes, group chat are the current ones — *when they actually couple*.

## The failure mode that started this thread

Some nervous systems never couple to the official GUI.

A calendar is supposed to become external working memory. For some people it stays a foreign object. You translate every box into a private format, lose the translation, and get called unreliable.

That is not "can't use tools." That is a coupling mismatch. The extended mind thesis already predicts it: the extra bit only joins the mind if it speaks the same protocol.

If your native protocol is spatial, event-based, intensity-based, scene-based, or cartoon-timed, a grid of hours is the wrong codec.
