# internal GUI

Field note from the conversation that started this repo:

> I've never been able to use guided user interface because somehow I have my own internal one I need to map out. I can't follow a calendar, neither can I follow time properly.

Official time GUI = grid, hours, reminders, guided wizards.
Private time GUI = unmapped. Maybe spatial, stacked, weather-like, event-based, scene-based, intensity-based. Not nothing. Wrong port.

Until the private GUI is mapped, every external scaffold is Otto's notebook written in a language Otto does not read. It never joins the mind. It just accuses you.

Cartoon time is often closer to event-time and intensity-time than clock-time. That may be why animation couples when calendars do not.

## Mapping prompts (keep messy)

- When you *do* know what is next, how does it appear? Layout, pressure, scene, stack of now/not-now?
- Is a week a grid, a road, weather, weighted objects, or fog until urgency?
- What happens when a normal calendar opens? Wrong coordinates, empty boxes, fake labels, Teflon attention?
- Events ("after this, then") vs clock stamps — which one actually moves you?

Map first. Then, if you want an extended-mind prosthetic, build one that speaks *that* protocol instead of punishing you for failing Windows-95 time.
